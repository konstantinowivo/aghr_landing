## 🎓 Conceptos Principales

### Z-Index (Orden de capas)
```
z-index: 0   → Animación (background)
z-index: 1   → Overlay
z-index: 2   → Contenido (encima)
```

### Timing (Velocidad de entrada)
```
1.5s  → Rápida (energética)
2.0s  → Normal (elegante) ← ACTUAL
2.8s  → Lenta (cinematográfica)
```

### Opacidad (Visibilidad)
```
0.05-0.08  → Muy sutil
0.10-0.15  → Normal ← ACTUAL
0.20-0.25  → Dramática
```

### Transform (Movimiento)
```
translateX(0)    → Posición inicial (izquierda)
translateX(1920px) → Posición final (derecha)
```
